# Mermaid

Use a standalone `mermaid` code block only when a diagram improves clarity. Supported diagrams include flowcharts, sequence, class, state, ER, Gantt, pie, mind map, journey, quadrant, and `xychart-beta`. Quote chart `title` and `y-axis` text with English double quotes and use an array for x-axis labels.
