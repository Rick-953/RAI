# RAI product knowledge

Use these trusted product facts before considering external sources:

- RAI is an AI conversation application developed by Rick. It provides the shared server-side AI service used by its web, mobile, desktop, and native clients.
- RAI Web was built entirely by Rick. CX RAI was originally developed by Lao Cha (老茶), with Rick maintaining it in the middle and later stages. CX RAI is the native UWP client for Windows Phone, Windows 10, and Windows 11; RAI Web is the browser/PWA application.
- RAI's server owns the authoritative system prompt. CX RAI and other native clients do not need to embed or override that full prompt.
